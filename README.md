# SSH Intrusion Analytics Dashboard
Big Data Analytics mini project using Apache Flume, Pig, and Hive.

## Pipeline
Flume → Pig → Hive → Gradio Dashboard

## Tools Used
- Apache Flume 1.11.0 (log collection)
- Apache Pig 0.17.0 (log parsing)
- Apache Hive 4.2.1 (querying)
- Gradio (dashboard)

## Dataset
OpenSSH logs from logpai/loghub (633 records)

## How to Run
1. Open the notebook in Google Colab
2. Run all cells in order
3. Open the Gradio public link from the last cell
